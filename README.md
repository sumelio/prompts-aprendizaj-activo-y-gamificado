# prompts-aprendizaj-activo-y-gamificado
Sistema de prompts para aprendizaje activo y gamificado

## Cómo usarlo — flujo de trabajo:
El sistema está diseñado como un ciclo cerrado:
### Prompt 1 → Define tu ruta: qué quieres aprender, por qué, con qué enfoque. Te da fases, recursos y criterios de salida claros.
### Prompt 2 → Aprende de forma activa: el tutor te enseña con preguntas socráticas estilo Platón, XP y niveles. No te da respuestas — te hace pensar.
### Prompt 3 → Construye algo real: un mini-proyecto de 3–7 días, específico para tu motivación, con entregable concreto y modo difícil opcional.
### Prompt 4 → Evalúa honestamente: mide comprensión, aplicación, resolución de problemas e independencia. Te dice si estás listo para avanzar o qué reforzar primero.

Truco clave para que funcionen bien: siempre pega el contexto acumulado en cada prompt — especialmente en el 3 y el 4. La calidad de la evaluación final depende de cuánto contexto le das al modelo sobre tu proceso completo.
